# Sonarick PWA — прототип

## Что уже работает
- Адаптивный тёмный интерфейс для iPhone.
- Разделы «Обзор», «Статистика», «Будильник», «Профиль».
- Настройка времени будильника и окна пробуждения.
- Сохранение настроек локально на устройстве.
- PWA manifest, service worker и офлайн-кэш после первого открытия.

## Ограничения iOS PWA
- Веб-приложение не имеет прямого доступа к HealthKit / Apple Health и не может самостоятельно читать измерения Apple Watch.
- Нельзя надёжно гарантировать фоновый звук или вибрацию в заданное время при закрытом Safari/заблокированном iPhone.
- Переключатель Apple Watch в прототипе — только настройка будущей интеграции, не подключение к часам.
- Показатели сна на экране демонстрационные.

## Установка на iPhone
PWA необходимо разместить на HTTPS-хостинге. После публикации откройте адрес в Safari → «Поделиться» → «На экран Домой» → «Добавить».

Для публикации без Mac можно использовать GitHub Pages через Safari на iPhone: создать репозиторий, загрузить файлы, включить Settings → Pages → Deploy from a branch. Затем открыть выданный HTTPS-адрес в Safari и добавить на экран Домой.

## Следующий этап для реального трекинга
Для чтения Apple Health потребуется нативный iOS-компонент с HealthKit и процессом распространения/подписания приложения. PWA может быть интерфейсом, но сама по себе не заменяет этот компонент.
